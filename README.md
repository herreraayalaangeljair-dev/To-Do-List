# To-Do List Web Application

Una aplicación web de gestión de tareas sencilla, intuitiva y eficiente, diseñada para organizar tu día a día. Construida con tecnologías web modernas, permite llevar un control total de tus pendientes con persistencia de datos local.

## Características Principales

| Función | Descripción |
| :--- | :--- |
|  **Gestión de Tareas** | Agrega nuevas tareas de manera rápida. |
| **Modificación** | Edita el contenido de tus tareas existentes en cualquier momento. |
| **Eliminación** | Borra tareas que ya no necesites. |
| **Filtrado** | Oculta o muestra tus tareas completadas con un solo clic. |
|  **Persistencia de Datos** | Gracias a `localStorage`, tus tareas se guardan en el navegador y sobreviven a un refresco de página. |
